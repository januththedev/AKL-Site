- AKL Guide: source-attributed answers for reach, named clients, leadership, historical deployments, licence and recognition. These reviewed answers run immediately in the browser without a model or API round trip; the server uses the same rules before any optional model call. Existing vacancy and sensitive-outcome boundaries remain in place.

## Source fidelity

The PDF contains 179 printed client rows. One exact repeated Wooden Bakery name is omitted, leaving 178 unique printed names. Similar-looking names are retained because they may describe distinct entities. This count is not advertised as 178 independently verified current contracts.

The founding date is August 1980. The live experience calculation uses the current Asia/Colombo year. The reported deployment total remains historical rather than being animated as a growing live counter.

The Chairman's message is attributed to C. Mohamed Nassar, Chairman / MD, as printed in the November 2025 profile. Licence and recognition statements are similarly attributed to the profile and do not claim live regulatory verification.

Eight genuine logo assets were separately matched to profile names. Ambiguous identities were omitted. Marks retain their colours and use white/dark surfaces according to legibility. Logos are self-hosted with no external logo lookup or tracking request.

The employer portfolio and private portfolio-link behaviour were preserved. Published Moments continue to supply gallery and scroll photography; the new opening uses the verified client marks.
